# Прогресс OLX Hunter

Обновлено: 2026-10-18.

## Реализовано

- Создан Git-репозиторий и базовая структура проекта.
- Добавлены безопасный шаблон окружения и правила исключения секретов/рабочих данных из Git.
- Создан backend-каркас FastAPI с request ID и единым прикладным форматом ошибок.
- Добавлен заменяемый интерфейс `ListingSource` и начальный адаптер OLX.
- Реализован чистый импорт и обратная сборка URL OLX: цена, валюта, продавец, сортировка, непрозрачные параметры, удаление tracking/page.
- Ссылки других доменов, нестандартные порты, credentials и некорректные диапазоны цены отклоняются.
- Сетевой источник честно возвращает `not_configured`; живой сбор пока выключен.
- Зависимости backend зафиксированы в `backend/uv.lock`.
- Добавлены SQLAlchemy-модели всех основных сущностей раздела 22 и первая Alembic-миграция.
- Реализована явная dev-аутентификация с привязкой к `OWNER_TELEGRAM_ID`; произвольный первый посетитель владельцем не становится.
- Реализованы API импорта ссылки, редактирования черновика и CRUD поиска с проверкой владельца и optimistic revision.
- Ссылка отдельного объявления распознаётся, но не может быть ошибочно запущена как мониторинг выдачи.
- Добавлены HTML-парсеры выдачи и полной карточки на контролируемых фикстурах: рекламные блоки пропускаются, продвинутая и органическая копии дедуплицируются.
- Добавлена детерминированная фильтрация цены, групп обязательных слов, отрицательных слов со случаем простого отрицания и accessory-only режима.
- Реализованы версии объявлений, связи с несколькими поисками, baseline без массовой рассылки и outbox-события `new_listing`/`price_drop`.
- Реализовано каскадное удаление объявления, его истории, saved-состояния и связей только после двух подтверждённых проверок недоступности; блокировка/сетевой сбой удалением не считаются.
- Реализована проверка Telegram Mini App `initData` по официальному HMAC-алгоритму, ограничение возраста, owner allowlist, подписанная HttpOnly-сессия и CSRF-защита изменяющих запросов.
- Исправлена проверка Mini App `initData`: поле Telegram `signature` теперь сохраняется в HMAC data-check-string; добавлен регрессионный тест для такого payload.
- Уточнено поведение строгих отрицательных слов: они не выполняют смысловой анализ отрицания; такой анализ будет доступен только через ИИ.
- Добавлены API ленты и полной карточки находки, фильтр сохранённых и изменение saved/hidden/seen/note с проверкой владельца.
- Добавлен ручной запуск проверки с возвратом существующего active run и честным состоянием `not_configured`, пока HTTP-источник выключен.
- Решения фильтра приведены к контракту `match|reject|uncertain`.
- Собран React/Vite Mini App с адаптивной мобильной нижней навигацией и desktop sidebar; основные разделы — «Поиски», «Находки», «Настройки».
- Реализованы импорт и редактор черновика, создание/пауза/ручная проверка поиска, общая лента, фильтр сохранённых, optimistic bookmark и полная карточка с переходом в OLX.
- Добавлены загрузочные, пустые, ошибочные и отключённые состояния; интерфейс использует Telegram theme/safe-area и внешний link adapter.
- Сервер пересобирает URL после изменения распознанной цены; клиент не конструирует OLX URL самостоятельно.
- Frontend-зависимости зафиксированы в `package-lock.json`; после обновления Vitest `npm audit` не находит уязвимостей.
- Добавлен aiogram-бот с owner allowlist, командами `/start`, `/app`, `/help` и импортом OLX-ссылки через общий `SearchService`.
- Добавлена доставка outbox с двумя кнопками, журналом попыток, обработкой `429`, блокировки бота и состоянием `delivery_unknown` без опасного автоматического повтора.
- Добавлены Celery worker/beat задачи для планирования due-поисков, запуска scan и доставки pending-уведомлений.
- Добавлен безопасный media pipeline: HTTPS/CDN allowlist, DNS/IP-проверка против SSRF, ручная проверка redirect, лимиты bytes/pixels, Pillow decode и генерируемые checksum-пути.
- Изображения загружаются только для подходящих объявлений, выдаются через owner-protected API и обрабатываются отдельной Celery-задачей.
- Добавлен OpenRouter-клиент по актуальному API: каталог совместимых моделей, strict JSON Schema, `require_parameters`, отключённый fallback и проверка доказательных цитат.
- Реализованы дневной бюджетный резерв до ИИ-вызова, учёт фактической/неопределённой стоимости, кэш оценки и отображение value label/summary в ленте.
- Добавлены versioned owner settings, usage API и CSV/JSON-экспорт на 24 часа; CSV защищён от formula injection.
- Реализован opt-in HTTP-адаптер OLX: ограниченные redirects/body/timeouts, отдельные состояния blocked/partial/removed, разбор выдачи и догрузка полной карточки перед фильтрацией.
- Добавлены Dockerfile backend/gateway, Caddy и Compose-сервисы `gateway/api/bot/worker/scheduler/postgres/redis` с persistent volumes и healthchecks.
- Добавлен браузерный OLX-источник на Playwright/Chromium с отдельным флагом `SOURCE_BROWSER_ENABLED`; CAPTCHA и challenge возвращаются как `blocked`.
- Парсер обновлён под текущую разметку OLX: карточки выдачи с `ad-card-title`, цена, город, состояние и превью; полная карточка с описанием, параметрами, датой публикации, профилем продавца, рейтингом и всеми доступными фото. Новая разметка покрыта локальными фикстурами.
- API находок и подробная карточка Mini App теперь отдают и показывают состояние, дату публикации, извлечённые параметры и публичные сведения продавца; готовые изображения отображаются горизонтальной галереей.
- Celery-worker освобождает asyncpg pool перед закрытием event loop каждой фоновой задачи; это устраняет повторное использование соединения из другого asyncio-loop.
- `scripts/setup` генерирует внутренние секреты; добавлены backup, restore и restore-test для чистой PostgreSQL-базы.
- README и документация запуска, архитектуры и эксплуатации приведены в соответствие с фактически собранными компонентами.
- Регулярный обход проверяет до 3 страниц с дедупликацией ID; фоновая актуальность проверяет старые ссылки раз в сутки и повторяет первый подтверждённый 404/410 не раньше чем через 6 часов.
- Скидки по умолчанию выключены и включаются для конкретного поиска в Mini App; сравнение использует последнюю успешно сообщённую цену, локальные media-файлы удаляются вместе со снятой карточкой.
- Редактор поиска принимает обязательные/запрещённые слова и необязательные OpenRouter model ID/инструкцию; истёкшие экспорты очищаются фоновой задачей.
- Для локального HTTP-адреса бот не создаёт недействительную Telegram Web App-кнопку: вместо ошибки сообщает локальный URL; inline Mini App в Telegram требует публичный HTTPS-адрес.
- Добавлена локальная панель Portainer для управления Docker и документирован инспектор ngrok на `127.0.0.1:4040`.
- Добавлен MVP автономного исследования: постоянные `research_sessions`, результаты по каждому лоту и журнал этапов. Прогресс сохраняется после каждого объявления, поэтому queued/running-сессии можно продолжать после перезапуска worker.
- Новый режим использует существующий безопасный OLX-источник и общий upsert объявлений: остаются история карточки, изображения и дедупликация между поисками и исследовательскими сессиями.
- Luna/OpenRouter получает объявления последовательно с компактной сводкой максимум пяти текущих лидеров, строгой JSON Schema и защитой от prompt injection. Для каждого результата сохраняются оценка 0–100, уверенность, аргументы, риски, пропуски, доказательства и токены.
- Добавлены лимит бюджета исследования, оценочная и фактическая стоимость, cached-input token счётчик только когда он возвращён провайдером, безопасная остановка при неизвестной цене модели или исчерпании лимита.
- Добавлен API исследовательских сессий, результатов, истории этапов и capabilities реестра площадок. OLX отмечен рабочим источником; Prom/Rozetka показаны как будущие адаптеры и не выдаются за работающий live-сбор.
- Добавлена переменная `OPENROUTER_RESEARCH_MODEL`. Модель не задаётся фиктивным значением: её точный ID должен присутствовать в `/api/v1/ai/models` для ключа пользователя.
- Mini App получил раздел «ИИ-поиск»: свободный запрос, понятный статус доступности площадок, история сессий, живое обновление этапов и рейтинга, пауза/продолжение/остановка, карточки с аргументами и ссылкой в OLX. Он использует ту же существующую оболочку и стиль, без дублирования обычного мониторинга.
- Worker атомарно забирает сессию в lease на пять минут. Планировщик повторно запускает только просроченную сессию после перезапуска, поэтому параллельный ручной/плановый запуск не анализирует одни и те же лоты дважды.
- OpenRouter-каталог для `openai/gpt-6-luna` не отдаёт `pricing.request`, что означает отсутствие фиксированной цены за запрос. Учёт теперь корректно использует $0 для этого необязательного компонента и всё равно требует известные цены prompt/completion.
- Для Luna проверена реальная строгая JSON Schema: Pydantic-схемы рекурсивно получают `additionalProperties: false`. Принудительный выбор провайдера убран, потому что он исключал все доступные маршруты; OpenRouter теперь выбирает совместимый маршрут сам, сохраняя strict structured output.
- Live-тест показал, что подробный JSON Luna может быть обрезан до закрывающей скобки. Контракт ограничивает длину каждого поля и число пунктов, а предел исследовательского ответа поднят до 2 400; бюджетная оценка использует то же значение.
- Проверка доказательств нормализует Unicode и пробелы: цитаты из украинских атрибутов не теряются из-за JSON `\\u`-экранирования, но всё так же обязаны реально присутствовать в данных объявления.
- Если Luna один раз вернула недословную `evidence.quote`, агент делает только одну исправляющую попытку с явным требованием дословной цитаты и суммирует токены обеих попыток в расходах сессии.

## Открытые проблемы

- Подробная UI-спецификация `OLX_HUNTER_UI_PROMPT.md` не предоставлена. До её появления интерфейс реализуется по разделу 22 плана; окончательная UI-проверка будет нужна после добавления файла.
- Прямой HTTP-источник OLX получает `403` от CloudFront; для локальной конфигурации включён Playwright-источник, его стабильность и лимиты нужно наблюдать на реальных поисках.
- `SOURCE_HTTP_ENABLED` включён в локальном `.env`, но контрольный запрос к `https://www.olx.ua/uk/` из API-контейнера получает `403` от CloudFront; live-мониторинг пока заблокирован самим источником.
- Нет внешних реквизитов Telegram, OpenRouter и публичного HTTPS-размещения.
- Docker Compose runtime проверен на машине: образы собраны, PostgreSQL/Redis/API healthy, gateway и bot запущены. Полный Telegram/OLX live smoke test ещё требует публичного HTTPS и включения источника.
- `openai/gpt-6-luna-flex` не найден в каталоге подключённого ключа OpenRouter на 2026-10-18. Его заменил подтверждённый `openai/gpt-6-luna`, записанный в локальный игнорируемый `.env`; сессия всё равно сообщит `model_not_available`, если модель исчезнет из каталога конкретного ключа.
