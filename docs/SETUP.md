# Настройка

Проект пока находится в активной реализации. Необходимые внешние значения перечислены в `.env.example`; рабочие ключи не должны попадать в Git.

`scripts/setup` создаёт `.env` с правами `0600`, генерирует внутренний `SESSION_SECRET` и оставляет внешние поля пустыми. Без Telegram-токена, ID владельца и публичного HTTPS-адреса локальные API и интерфейс могут работать, но живой Telegram Mini App не считается настроенным.
